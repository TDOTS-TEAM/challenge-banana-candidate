# challenge-banana-candidate

## Getting started

1. Download `challenge-banana-candidate.zip` from this repository.
2. Unzip it and follow the instructions in `challenge-banana-candidate/README.md` and `challenge-banana-candidate/docs/challenge.md`.

## Submitting your work

When you have finished:

1. Compress your project folder into a `.zip` file. Leave out `node_modules`, build output and any `.env` files that contain secrets.
2. Email the `.zip` to **hr@tdots.es**, with your full name in the subject line.

If you have any questions about the challenge, contact **hr@tdots.es**.
